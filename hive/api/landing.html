Security

Privacy by architecture.

Not a policy. A design choice.

🏠

Self-hosted

Your data never leaves your server. No cloud dependency, no vendor lock-in.

🔑

Your keys

API keys stored encrypted locally. You control access to every provider.

🛡️

Guardrails

SELECT-only database queries. Agents can read, never write without permission.

📦

Docker isolation

Each component runs in its own container. Clean separation, easy audit.

📝

Audit logs

Every request, every agent call, every cost tracked in JSONL logs.

🔒

E2EE P2P

Signal Protocol encryption. Forward secrecy. Your messages, your keys only.
